## 框架

- `Hugo` + `Blowfish`

## 新文章

- `hugo new posts/你的文章檔名.md`

## 服務啟動

- `hugo server --disableFastRender`

### 版本更新

- `Hugo`
    - `hugo mod get -u`

- `Blowfish`
    - `git submodule update --remote --merge`
